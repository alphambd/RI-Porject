OBSERVATIONS :
------------------------------------------------------
I - Classement des performances : 5 des configurations optimisées
  1. k1=1.2, b=0.75 (nostem) - MAgP: 0.1766 ⭐
  2. k1=1.2, b=0.6 (porter) - MAgP: 0.1758
  3. k1=1.2, b=0.5 (porter) - MAgP: 0.1739
  4. k1=1.2, b=0.7 (porter) - MAgP: 0.1729
  5. k1=1.2, b=0.4 (porter) - MAgP: 0.1726

II - 
A) Impact du paramètre b (contrôle la normalisation longueur):
Valeurs optimales de b : 0.4 - 0.7

Amélioration : 
  b = 0.5-0.7 : MAgP > 0.172 (runs #2-5)
  b = 0.75 (valeur par défaut) : MAgP 0.1766 (nostem)

Dégradation : 
  b < 0.3 : Performance dégradée (MAgP < 0.167)
  b > 0.8 : Chute significative (MAgP < 0.155)
  b = 1.0 : Pire performance (MAgP 0.1096)

Conclusion : 
- Une normalisation modérée des longueurs (b ≈ 0.5-0.7) est optimale. 
- Une normalisation trop forte (b > 0.8) ou trop faible (b < 0.3) nuit aux performances.

B) Impact du paramètre k1 (contrôle la saturation TF)
Valeurs optimales de k1 : 0.2 - 1.6

Amélioration :
  k1 = 0.2-1.6 : MAgP > 0.153 (runs #7-17)
  k1 = 1.2 (valeur par défaut) : MAgP 0.1766 (nostem)

Dégradation :
  k1 < 0.2 : Performance très faible (MAgP 0.0425)
  k1 > 2.0 : Dégradation progressive (MAgP < 0.153)
  k1 = 4.0 : MAgP 0.1255

Conclusion : 
- BM25 nécessite une saturation TF modérée (k1 ≈ 1.0-1.6). 
- Des valeurs trop faibles désactivent la saturation, tandis que des valeurs
