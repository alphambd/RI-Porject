EXERCICE 1: XML articles runs 
=============================================================

Il a été réalisé en 2 phases : Test de 12 runs (Weighting + Stopwords + Stemmer) et Optimisation de BM25.

-------------------------------------------------------------
1 - Test de 12 runs (Weighting + Stopwords + Stemmer) : 
-------------------------------------------------------------

Configuration : 
- Weighting : LTN, LTC, BM25 (3)
- Stemming : nostem, porter (2)  
- Stop-words : nostop, stop671 (2)
- Total : 3 × 2 × 2 = 12 runs

BM25 (stop671, porter)  -> MAgP = 0.1950
BM25 (stop671, nostem)  -> MAgP = 0.1906
BM25 (nostop, nostem)   -> MAgP = 0.1620
BM25 (nostop, porter)   -> MAgP = 0.0971

ltn (stop671, porter)   -> MAgP = 0.1583
ltn (stop671, nostem)   -> MAgP = 0.1497
ltn (nostop, nostem)    -> MAgP = 0.1459
ltn (nostop, porter)    -> MAgP = 0.1396

ltc (stop671, porter)   -> MAgP = 0.0441
ltc (nostop, porter)    -> MAgP = 0.0411
ltc (stop671, nostem)   -> MAgP = 0.0368
ltc (nostop, nostem)    -> MAgP = 0.0344


Analyse des résultats
-------------------------------------------------------------

Comparaison des modèles
---------------------------
Les résultats montrent que le modèle BM25 est globalement le plus
performant. Le meilleur score obtenu avec BM25 est MAgP = 0.195.
Le modèle ltn présente des performances intermédiaires, avec un score
maximal d’environ MAgP = 0.1583.
Le modèle ltc est nettement moins performant, avec des scores très
faibles (MAgP < 0.05).

Ces résultats confirment que BM25 est plus robuste que les schémas
SMART classiques sur cette collection.


Impact des stop-words
---------------------------
L’utilisation de la liste de stop-words stop671 améliore systématiquement
les performances pour BM25 et ltn.
À l’inverse, l’absence de stop-words entraîne une baisse significative
des performances, en particulier pour BM25.


Impact du stemming
---------------------------
L’utilisation du stemmer de Porter améliore les performances de BM25,
notamment lorsqu’il est combiné avec l’utilisation des stop-words.
Pour le modèle ltn, l’impact du stemming est plus modéré mais reste
globalement positif.


Meilleure configuration observée
--------------------------------
La meilleure configuration issue de ces 12 runs est :

- Modèle : BM25
- Stop-words : stop671
- Stemmer : Porter
- Paramètres BM25 : k1 = 1.2, b = 0.75

Cette configuration atteint :
- MAgP = 0.195
- iP[0.1] = 0.5584

Elle est retenue comme baseline pour la suite du TP.


-------------------------------------------------------------
2 - Optimisation de BM25 : 
-------------------------------------------------------------

Après avoir identifié la meilleure configuration générale, une
optimisation des paramètres du modèle BM25 a été réalisée.
D’après les résultats du "Practice 4", la valeur k1 = 1.2 s’est révélée
la plus efficace. Ce paramètre est donc fixé, et seule la valeur de b
est optimisée.

Les valeurs de b testées appartiennent à l’intervalle [0.4, 0.8].


Résultats de l’optimisation
---------------------------
Les résultats montrent que les meilleures performances sont obtenues
pour des valeurs de b comprises entre 0.5 et 0.7.
La meilleure performance globale est atteinte pour b = 0.65.

b = 0.4  -> MAgP = 0.2056
b = 0.5  -> MAgP = 0.2069
b = 0.6  -> MAgP = 0.2088
b = 0.65 -> MAgP = 0.2113 (meilleur score)
b = 0.7  -> MAgP = 0.2055
b = 0.8  -> MAgP = 0.1857


Configuration finale retenue
----------------------------
La configuration BM25 optimisée est la suivante :

- Modèle : BM25
- k1 = 1.2
- b = 0.65
- Stop-words : stop671
- Stemmer : Porter

Cette configuration atteint :
- MAgP = 0.2113
- iP[0.1] = 0.5178

Elle constitue la meilleure baseline textuelle pour les exercices
suivants exploitant la structure des documents (liens et anchors).
