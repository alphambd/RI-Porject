Analyse des résultats
-------------------------------------------------------------

Comparaison des modèles
---------------------------
Les résultats montrent que :
- BM25 est plus robuste que les schémas SMART classiques sur cette collection.

Impact des stop-words
---------------------------
- L’utilisation de la liste de stop-words stop671 améliore systématiquement
  les performances pour BM25 et ltn.
- À l’inverse, l’absence de stop-words entraîne une baisse significative
  des performances, en particulier pour BM25.

Impact du stemming
---------------------------
- L’utilisation du stemmer de Porter améliore les performances de BM25, notamment 
  lorsqu’il est combiné avec l’utilisation des stop-words.
- Pour le modèle ltn, l’impact du stemming est plus modéré mais reste globalement positif.


Meilleure configuration observée
--------------------------------
La meilleure configuration issue de ces 12 runs est :

- Modèle : BM25
- Stop-words : stop671
- Stemmer : Porter
- Paramètres BM25 : k1 = 1.2, b = 0.75

Cette configuration atteint :
- MAgP = 0.2088
- iP[0.1] = 0.4987

Elle est retenue comme baseline pour l'optimisation de BM25.

EXERCICE 2: XML elements runs
=============================================================

Objectif : exploiter la structure XML via une approche Fetch & Browse.

-------------------------------------------------------------
Méthode
-------------------------------------------------------------

Une sélection naïve du seul élément le plus spécifique conduit
à une domination des paragraphes (≈95%) et à un faible MAgP (0.059).

Pour corriger ce biais, un seuil de pertinence est introduit
et un bonus est appliqué selon le type d’élément :

- bdy : 1.0
- sec : 1.1
- p   : 1.2

Cette stratégie permet un meilleur équilibre entre granularités
et améliore significativement les performances.

Résultat :
- MAgP ≈ 0.17


-------------------------------------------------------------
Indicateurs « RI ciblée » 
-------------------------------------------------------------
Pour un exemple de run, nous avons obtenu les résultats suivants : 

RATE TARGET: 58.01% 
AVERAGE DEPTH: 5.41 depth
ARTICLE COUNT: 1182 articles

Conclusion : 
-------------------------------------------------------------
Sur l’ensemble des requêtes testées, le taux de ciblage moyen est
d’environ 58 %, ce qui signifie qu’en moyenne un peu plus de la
moitié du contenu des articles ciblés est effectivement retournée
sous forme d’éléments XML.

La profondeur moyenne se situe autour de 5 à 6, indiquant que les
réponses sont majoritairement situées à des niveaux fins de la
structure XML (sections, sous-sections ou paragraphes).

Degré de sortie min:      0

Ces statistiques montrent que la collection INEX possède une structure
de liens dense, avec un degré de sortie moyen relativement élevé.
La présence d’articles très fortement connectés (degré max = 1255)
suggère l’existence de documents centraux, susceptibles d’avoir une
forte importance structurelle.


-------------------------------------------------------------
Méthode
-------------------------------------------------------------

Le score final est obtenu par interpolation linéaire entre :
- le score BM25 (contenu)
- le score PageRank (liens)

Formule :
Score = alpha × BM25 + (1 - alpha) × PageRank

Le paramètre alpha contrôle l’importance relative du contenu
par rapport aux liens.

-------------------------------------------------------------
Tuning du paramètre alpha
-------------------------------------------------------------

alpha = 0.7  -> MAgP = 0.1973
alpha = 0.8  -> MAgP = 0.1971
alpha = 0.85 -> MAgP = 0.1978
alpha = 0.9  -> MAgP = 0.1965
alpha = 0.95 -> MAgP = 0.2100
alpha = 0.99 -> MAgP = 0.2113 (score baseline)

-------------------------------------------------------------
Analyse
-------------------------------------------------------------
Les meilleures performances sont obtenues pour une valeur élevée
de alpha (0.95).

Cela indique que :
- le contenu textuel reste dominant
- les liens apportent un gain complémentaire limité

-------------------------------------------------------------
Conclusion
-------------------------------------------------------------
- Cette expérience montre que l’exploitation de la structure de liens
  via PageRank ne permet pas de surpasser une forte baseline BM25
  sur la collection INEX.

- Les performances optimales sont obtenues lorsque le score est
  très majoritairement basé sur le contenu textuel (alpha = 0.99).

EXERCICE 5: XML articles runs, exploiting anchors
=============================================================

Dans cet exercice, nous exploitons les textes d’ancrage (anchor texts)
associés aux balises <link> afin d’enrichir la représentation textuelle
des articles. 

-------------------------------------------------------------
Méthode
-------------------------------------------------------------
Deux scores sont combinés :
- score de contenu (BM25 sur l’article cible)
- score basé sur le texte des ancres

Formule :
Score = ac × Score_content + aa × Score_anchor

avec :
- ac : alpha_content
- aa : alpha_anchor

-------------------------------------------------------------
Tuning des paramètres
-------------------------------------------------------------
ac0.8_aa0.2 : MAgP = 0.1023
ac0.8_aa0.5 : MAgP = 0.0813
ac0.8_aa0.8 : MAgP = 0.0750
ac0.8_aa1.0 : MAgP = 0.0725

ac1.0_aa0.2 : MAgP = 0.1086
ac1.0_aa0.5 : MAgP = 0.0873
ac1.0_aa0.8 : MAgP = 0.0774
ac1.0_aa1.0 : MAgP = 0.0750

ac1.2_aa0.2 : MAgP = 0.1130
ac1.2_aa0.5 : MAgP = 0.0938
ac1.2_aa0.8 : MAgP = 0.0802
ac1.2_aa1.0 : MAgP = 0.0766

ac1.0_aa0.0 : MAgP = 2113 (score baseline)

-------------------------------------------------------------
Analyse
-------------------------------------------------------------
* Les meilleures performances sont obtenues lorsque :
- alpha_content est élevé
- alpha_anchor est très faible (≈ 0)

* Lorsque le poids des ancres augmente, les performances chutent rapidement.

-------------------------------------------------------------
Conclusion
-------------------------------------------------------------
- Les ancres apportent une information complémentaire, mais doivent être faiblement pondérées.
- Le contenu textuel reste la source principale de pertinence.
